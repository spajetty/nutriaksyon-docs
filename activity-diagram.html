SYSTEM DESIGN

Activity diagram

How the system behaves, flow by flow. Each diagram below follows one task from the role that starts it to the record the system keeps.

01

Student measurement

The teacher enters the class' height and weight in the growth monitor; the system computes BMI and height-for-age and updates the student profile and reports.

02

Feeding session

The coordinator schedules a session, picks a meal the available crops can support, and closes the day by marking attendance.

03

Account creation & access

The admin creates teacher and coordinator accounts, then allows or declines each access request before the account becomes active.

04

Admin token issuance

The SuperAdmin issues a single-use token that an admin must enter while signing up, so nobody can register as an admin on their own.
